# Academic Paper Recommendation System

This project investigates similarity measurement techniques for academic paper recommendation using a controlled experimental pipeline.

## Project focus
The project compares:
- lexical similarity using Term Frequency–Inverse Document Frequency
- semantic similarity using transformer-based sentence embeddings

## Dataset
The dataset is extracted from OpenAlex using publicly accessible scholarly metadata.

## Evaluation
Recommendation quality is evaluated using:
- Precision at k
- Recall at k
- F1-score
- Normalised Discounted Cumulative Gain at k

## Current stage
Implementation and evaluation pipeline under development for Coursework 2.
